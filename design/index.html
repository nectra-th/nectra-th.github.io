06

Motion & conventions

What every new component should inherit.

  • Transitions: 0.5s --ease-smooth (cubic-bezier .45,0,.55,1); entrances use --ease-lux.
  • Hover lift: interactive cards lift −2px (.gj-lift / .gj-soft); the new button system uses colour+shadow only, no lift.
  • Reduced motion: all animation/transition collapse to 0.01ms; carousels stop auto-advancing; hero video doesn’t autoplay.
  • fig-trim: text measured from Figma uses text-box-trim cap-height trimming — margins are cap-to-cap, so browser line-boxes match Figma’s trimmed boxes.
  • Hero overlay pattern: one gradient everywhere (“Rectangle 23”): transparent 47% → short 13% fade → flat 63% ink; vertical on mobile, horizontal (dark side = copy side) from md up. Video is full-opacity — the gradient is the only dimmer.
  • Gold rules: 2px gold-dark bars — 114px under section titles, 64px under band titles, 32px in cards.
  • Section boundaries: dark bands close with a 4px --color-rule bottom border.
  • Radius: buttons 4px · cards 12px (rounded-xl) · media 16px (rounded-2xl); full-bleed mobile media drops rounding.
  • Carousel dots: 10px divider dots, active = 26px gold pill.
  • Interaction classes: legacy .gj-* set still powers nav links, calendar cells, time slots, gallery arrows, review cards — see globals.css.
